# CD Gestão Empresarial — v96

## Objetivo
Elevar o acabamento profissional do ERP em celular, tablet e notebook, mantendo compatibilidade com Render/GitHub e sem alterar regras críticas de negócio.

## Ajustes aplicados
- Interface com aparência mais profissional em cards, tabelas e modais.
- Tabelas largas com rolagem horizontal mais segura e cabeçalho fixo.
- Áreas de toque maiores para uso no celular.
- Melhor comportamento de modais em telas pequenas.
- Login mantido com botão de olho simples para mostrar/ocultar senha.
- Cache visual atualizado para `v96`.
- Healthcheck atualizado para retornar `v96`.

## Observação
Esta versão foca refinamento visual, usabilidade e responsividade. A refatoração arquitetural completa em módulos deve ser feita em uma versão futura, com testes regressivos por fluxo.
